# Летописец — ИИ-мастер D&D 5e

Одностраничная игра (один HTML-файл): ИИ ведёт кампанию по правилам 5e, движок честно считает броски, хиты и ячейки.

- Dev-версия с Claude: https://claude.ai/artifact/P57mHRoND46VBDvvfJqoJh
- Публичная версия (GitHub Pages): https://mbnotoriety.github.io/letopisets/ — после включения Pages в настройках репозитория (Settings → Pages → Deploy from branch → main / root).

## Рассказчик и портреты
Кнопка «Рассказчик» вверху открывает «ИИ и портреты». Режим «Авто» берёт лучший доступный вариант и при сбое или лимите переходит к следующему:

| Рассказчик | Где работает | Что нужно игроку |
|---|---|---|
| Claude | claude.ai | аккаунт Claude |
| Puter (Claude, GPT, Gemini) | публичная версия | вход в бесплатный аккаунт Puter (можно временный) |
| Pollinations | публичная версия | вход через GitHub или ключ `sk_…` |
| Gemini / Groq / OpenRouter | публичная версия | свой бесплатный ключ |
| Свой сервер | публичная версия | адрес OpenAI-совместимого API (например, `worker/proxy.js` на Cloudflare) |
| ИИ в браузере (WebLLM) | публичная версия, WebGPU | скачать модель ~2 ГБ |
| Pollinations без входа | публичная версия | ничего (часто перегружен) |

Портреты: подключения Claude (Hugging Face) → Puter → токен Hugging Face → Pollinations (без входа — 1 портрет в 45 секунд) → рисованные.

Внутри claude.ai страница не может обращаться к внешним сервисам (политика песочницы), поэтому там работает только Claude; для гостей — публичная версия.

## Структура
- `index.html` — собранная игра (v24).
- `src/` — модули, которые вклеиваются в HTML: создание героя, путешествия, бой, НПС, полировка, уровни, диалоги, спутники, провайдеры ИИ, мобильная вёрстка.
- `build/` — скрипты патчей и сборки (`build24.sh`).
- `tests/` — Playwright-тесты; `mock.js` подменяет ИИ, `t31.py` проверяет гостевой режим с поддельными API.
- `worker/` — бесплатный прокси рассказчика для Cloudflare Workers (ключи в секретах воркера).
- `assets/snd/` — звуки (Battle for Wesnoth, GPL).
- `versions/` — снимки HTML прошлых версий.
