# Летописец — ИИ-мастер D&D 5e

Одностраничная игра (один HTML-файл): ИИ ведёт кампанию по правилам 5e, движок честно считает броски, хиты и ячейки.

Опубликовано как артефакт Claude: https://claude.ai/artifact/P57mHRoND46VBDvvfJqoJh

## Структура
- `index.html` — собранная игра (текущая версия, v23).
- `src/` — исходники модулей, которые вклеиваются в HTML (создание героя, путешествия, бой, НПС, полировка, уровни, диалоги, спутники, мобильная вёрстка).
- `build/` — скрипты патчей и сборки (`build23.sh` собирает v23 из v21 + патчей).
- `tests/` — Playwright-тесты (`python3 tests/t30.py <папка с mock.js>`), `mock.js` подменяет ИИ.
- `assets/snd/` — звуки (Battle for Wesnoth, GPL), `files.json` — карта публикации звуков.
- `versions/` — снимки HTML прошлых версий.
